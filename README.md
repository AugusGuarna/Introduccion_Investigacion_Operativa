# Operations Research & Optimization (UBA)

This repository contains academic materials and implementations for the **Introduction to Operations Research** course at the University of Buenos Aires. It focuses on mathematical modeling for decision-making and resource optimization.

### 🚀 Key Technical Features
- **Linear Programming:** Modeling and solving optimization problems using **ZIMPL** and **SCIP**.
- **Theoretical Analysis:** Formal proofs and exercises covering duality, sensitivity analysis, and network flow.
- **Problem Solving:** Implementation of various solvers to optimize objective functions under specific constraints.

### 📂 Repository Structure
- `/ZIMPL_SCIP_concepts`: Syntax and conceptual guides for optimization solvers.
- `/Guia_1` & `/Guia_2`: Solved problem sets focusing on linear and integer programming.
- `Resumen_2do_parcial.pdf`: Comprehensive theoretical summary of advanced optimization topics.

### 🛠️ Technical Stack
- **Tools:** ZIMPL, SCIP.
- **Concepts:** Simplex Method, Duality, Integer Programming, Combinatorial Optimization.
